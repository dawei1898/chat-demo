# P2 认证与授权验收

## 范围

仅邮箱密码与 Cookie 会话。邮箱是登录标识，不代表已验证所有权。用户已明确取消邮箱验证/密码找回及 Google/GitHub OAuth，不接发信服务、OAuth 应用或相关 UI。

本轮不部署、不开放公网注册，不读取或迁移旧浏览器数据。认证与限流测试在 Neon dev 的隔离事务内执行并回滚；不把测试 Cookie、密码或连接串写入输出。

## 必须验证的安全边界

1. 未登录、过期、撤销、退出后的业务请求拒绝访问。
2. 不同用户的会话读取、修改、删除、生成和取消不能越权。
3. Cookie 不向脚本开放，SameSite 与路径正确；HTTP 本地环境不冒称具备 HTTPS Secure，生产保护不移除。
4. 账户切换、跨标签页退出、认证失败时立即隐藏并清空当前内存聊天/草稿，停止本地流；旧响应不得回填新用户状态。
5. 活动生成关联真实认证会话，退出/过期/撤销后中止上游，不仅关闭页面展示。
6. 写请求 Origin 严格匹配；不接受客户端伪造用户 ID、认证 token 或转发 IP。
7. 限流为数据库原子持久计数，覆盖注册/登录，全局来源与登录标识分别约束。数据库失败时拒绝请求，不退化为无限放行。
8. 注册默认仅本地允许，并能显式关闭；不把局部限流当完整公网反滥用。

## 验收记录

本地P2实现与下列分层验证完成；生产部署与公网代理验证仍属于后续范围。

## 已验证的实现

- 0003 迁移已在 Neon dev 执行：auth_rate_limit 持久计数表、generation_run.auth_session_id（非令牌）。未修改其他环境或清理用户认证数据。
- 认证入口仅保留当前使用的白名单端点；取消的验证/恢复/OAuth 路径返回 404。
- 来源只认 Node socket，不信任 X-Forwarded-For。限流键为带域隔离的 HMAC，不持久保存原始邮箱/IP。
- 默认 local 注册同时要求配置 origin 与 socket 为回环；REGISTRATION_MODE=closed 全关。HTTP 本地 Cookie 为 HttpOnly/SameSite=Lax/Path=/，不虚称 Secure；生产启动保护仍在。
- 身份代次校验使迟到列表/详情/SSE 不得回填。失效清空内存会话与草稿，不碰旧 IndexedDB/localStorage。跨标签通过 BroadcastChannel 通知；正常焦点核验不丢草稿。
- 前台会话核验每20秒；活动生成每1.5秒核对session存在/过期，注销主动取消。属于有界失效，不承诺零延时。

## 自动化结果

- 32 项后端单测、4 项前端身份边界/竞态测试通过；前后端类型、lint、构建通过。
- `auth-integration.mjs` 使用真实 Better Auth handler 与 Neon dev 隔离schema事务，11项检查通过：注册、登录、Cookie、过期/撤销、跨用户、非法Origin、会话过期取消流、注销取消流、持久原子限流与429、已取消功能禁用。
- 集成测试最终整体回滚，确认临时schema不存在，没有public测试数据残留，不撤销用户真实会话，不调用模型。
- 浏览器升级后现有登录和聊天入口正常；未对用户正在使用的账号执行跨标签退出操作。多标签交互另用下述隔离浏览器场景验证，避免影响用户正在使用的账号。

## 运行边界

本机代理的请求共享loopback来源额度：全认证120次/分钟、登录20次/5分钟/来源及10次/5分钟/邮箱标识、注册5次/小时/来源。多标签/本机多用户共用来源额度；公网平台可信代理和风险识别不在此实现中。注册已设置autoSignIn:false；真实handler验证新/重复注册均200、token:null、无Set-Cookie，重复响应不含真实user id或旧资料。仍不宣称免验证注册可完全杜绝所有侧信道枚举。
