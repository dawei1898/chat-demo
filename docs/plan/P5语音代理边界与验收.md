# P5 语音代理边界与验收

## 本地实现

- 前端只请求同源 `/api/speech/asr`、`/api/speech/tts`；旧参数签名保留，但不读取或发送浏览器 API Key。
- 路由在来源检查和 Better Auth 会话鉴权后注册。ASR 的请求体上限独立放宽为 8 MiB + 16 KiB，其他业务请求仍是 128 KiB。
- ASR 只支持 MIME 为 audio/wav、audio/wave、audio/x-wav 的 PCM16 WAV。解析 RIFF 长度、fmt/data 唯一块、PCM 格式、声道、采样率、字节率、帧对齐与时长；最多 8 MiB、120 秒。不支持 Opus 或扩展 WAV fmt 首版。
- TTS 只允许 stella/tide，固定原始 PCM，汉字按 2、其他 Unicode 码点按 1，最多 10000 计费字符，输入 JSON 保守限制 60 KiB。接受实际供应商 audio/pcm（显式参数须符合24kHz/16bit/单声道/signed-integer）及兼容 application/octet-stream，不把 HTTP 200 JSON 错误作为音频播放。
- 单实例内每用户每分钟最多 10 次、最多 2 个进行中请求。不是持久化账单额度，也不是多实例/生产级限流。
- 上游连接 30 秒、读空闲 15 秒、整个请求 120 秒预算；ASR 返回最多 256 KiB，TTS 最多 5,760,000 字节（24kHz PCM16 单声道 120 秒）。超长朗读会断流，首版不承诺供应商最大 30 分钟音频。
- 客户端取消/总时限/读取失败会终止上游并释放槽位；每 2 秒核查发起 session 是否仍有效，查询预算 5 秒，失败关闭。注销不是同步零延迟取消。
- 不保存音频、原始输入或供应商错误。响应错误固定脱敏，上游 401 不映射为本地用户 401。

## 已验证

`../../server/tests/p5-speech.test.ts`：WAV 边界和畸形文件、TTS 声线及中文计费字符、额外参数拒绝、ASR 返回字段白名单、PCM 字节流、取消 reader、上游 401 脱敏、HTTP 200 JSON 非音频拒绝。所有供应商响应均为 mock。

## 尚未验收

- 未请求麦克风权限、未采集真实录音、未调用真实 ASR；TTS已完成下述授权短文本接口验证，不代表所有音色/长文本和播放实测完成。
- WAV/PCM 协议来自官方文档，但官方说明未明确 PCM 字节序；原播放器使用小端，需要获授权的短音频听测确认。
- 该原始 PCM HTTP 协议无业务终止标记，偶数字节的正常 EOF 不能完全证明供应商未截断语音。
- 尚无生产多实例限流、语音账单汇总或持久化额度。长请求仅为本地运行设计，未做 Vercel 生命周期验收。

参考：[官方 ASR](https://api-docs.deepseek.com/zh-cn/guides/asr/)、[官方 TTS](https://api-docs.deepseek.com/zh-cn/guides/tts/)。

## TTS 502 修复与真实短测

用户报告朗读502后，授权使用短文本“你好”诊断。实际供应商响应为HTTP200，Content-Type是`audio/pcm; rate=24000; encoding=signed-integer; bits=16; channels=1`；旧代理只允许`application/octet-stream`，误判合法PCM为502。已修复媒体类型兼容并严格验证显式音频参数，仍拒绝JSON和不兼容音频。

两次最小真实调用：直接供应商stella返回40320字节；修复后通过同一speechRoutes实现、测试身份的进程内代理，tide返回HTTP200/40320字节/偶数字节，耗时约3秒。测试身份仅在独立进程内注入，没有读取或修改用户Cookie/会话，没有保存或播放音频；不是浏览器扬声器听测。新媒体类型及参数负例测试通过，服务端类型/lint通过。

## 合成语音真实闭环补验

使用无隐私短文本“你好，语音测试。”，经实际前端 synthesize API、Hono speechRoutes、真实 DeepSeek TTS 返回 82,560 字节 PCM（1.72 秒）。包装为 82,604 字节 PCM16 WAV 后经实际前端 transcribe API、Hono、真实 ASR，精确返回原文本。总耗时 11.166 秒。身份和 session 查询仅在独立进程内注入，不读取真实用户 Cookie，不使用麦克风或用户音频。

该闭环验证当前账号 ASR/TTS 可用及小端 PCM 可被正确识别；不代表扬声器听感、浏览器播放/停止或完整麦克风流程通过。CUA 已只读确认8095有朗读与语音控件，但未操作真实账户内容或退出。
