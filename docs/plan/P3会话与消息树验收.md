# P3 会话与完整消息树验收

## 本轮目标

- 会话列表游标分页、加载更多、重试及去重，超过200条可访问。
- 会话revision并发控制：写入时核验预期版本，冲突提示并刷新，不自动重发模型请求。
- 消息正文按当前分支和历史窗口读取；树关系/版本索引与正文分离，不将部分视图当完整树保存。
- 模型上下文单独控制预算，不静默截断。UTF-8请求字节仅为保守大小预算，不冒称精确token估算。
- 编辑、重新生成、继续生成、切换版本的树结构、持久化及用户隔离回归。

## 安全与验证约定

只用 Neon dev；测试使用随机隔离schema和外层回滚，不处理旧浏览器数据，不调用真实模型。浏览器回归可使用真实前端加内存mock接口，明确与真实数据库集成验证分层。禁止以截断完整树的方式伪造按需加载，禁止忽略revision冲突或静默覆盖。

会话列表按更新时间排序，是实时列表而非冻结快照：静态数据验证无重漏；翻页时另一个设备更新旧会话，可能把它移动到已翻过区域，需刷新列表获取新顺序。去重只能消除重复，不能证明可变排序的快照一致性。

## 验收记录

### 已通过

- 前后端 TypeScript、lint、生产构建；前端 9 项自动化。后端 40 项单测已覆盖窗口、revision、部分 DTO 禁止写回及请求预算边界。
- Neon dev 随机隔离 schema、外层事务：250 条同微秒会话列表分页、稳定排序与去重、其他用户隔离、软删除过滤、非法游标；旧 revision 的 PATCH/DELETE/生成拒绝；122 节点窗口按 50/50/22 无重漏读取；超预算返回 413 且不创建生成或改变会话版本。
- 浏览器使用真实前端构建及内存 mock API：全部 251 条会话可访问；加载失败重试；160 条消息历史加载；发送→重新生成→切换旧回答→继续生成→编辑→切回旧分支，刷新后选中路径保留。没有用 mock 结果冒充真实模型调用。
- 8095 前端 HTTP 200、8096 健康检查正常；临时 8097 验收服务与测试标签页已关闭。

### 性能记录和未完成边界

- 122 节点、用户正文约 5 KB 的真实 DB 样本：50 条窗口 162,291 字节、约 1,951 ms（含 API 认证）；完整读取 337,492 字节、约 2,725 ms。单 SSE 快照 162,295 字节。这只是当次网络和样本记录，不是服务保证。
- 1000 节点两次集成在批量种子/完整性约束验证阶段远端断连，尚未进入窗口查询。已停止重复试跑，不能宣称 1000 节点数据库性能达标。
- 1000 节点内存投影约 2.12 ms，完整 JSON 2,627,632 字节、窗口+索引 217,573 字节。此结果不替代数据库性能验收。
- SSE 仍可能在连续快照重复传递完整轻量树索引；大树下带宽仍待优化。生成准备仍读取服务端完整树做一致性校验，并非全链路增量加载。
- 上下文预算固定 256 KiB，按最终模型请求 JSON UTF-8 字节核算，包含 system、工具和续写前缀；超限明确拒绝，不自动摘要、不删改历史，也不等同精确 token 限制。
- 本轮没有 schema 变更，不操作公共业务数据，不读取旧浏览器历史，不调用真实模型，不提交、推送或部署。

完整数据库生成分支流程：send/regenerate/continue/edit 四次模拟生成均完成且落库 revision 一致；旧分支恢复测试先后修正按数组下标比较、未先切换旧根的测试设计错误，最后修正尚未重跑，因此 P3-07 保留未验收。所有测试进程已退出，失败路径执行回滚/关闭连接，无 public 写入。
