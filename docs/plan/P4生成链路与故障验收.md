## 已实现的约束

- 幂等请求以用户和 key 唯一识别，并比较规范化请求摘要。相同请求返回 HTTP 200 JSON `{ replay, runId, status, conversationId }`，前端仅刷新现有结果，不重发模型调用；不同请求返回 409。历史任务摘要为空时明确拒绝猜测，不回填或改写旧任务。
- `0004_woozy_skrulls.sql` 只新增可空 `generation_run.request_hash`。已在锁定 dev 端点的临时表事务中验证并回滚，再通过正常迁移流程应用 dev；不涉及 main 或现有行内容。
- 错误只使用固定业务 code 和中文提示，上游认证失败不作为用户登录失效处理。最终事务失败或失去租约不能发送内存中的成功会话。
- 取消与完成在 generation 行锁上确定顺序；取消先落库则停止，完成先提交则后续取消不改变终态。
- 检查点保存正文及本次 usage；回收过期任务保留部分数据，既不虚构零用量也不自动重新请求模型。
- 模型阶段预算：总时长 240 秒、连接 30 秒、无有效模型进展 60 秒；累计上游响应 4 MiB；单次客户端写入 10 秒。SSE 解码单行/单事件默认 4 Mi 字符，不等同字节限制。
- 240 秒不是完整 HTTP 请求耗时保证：之后仍有数据库终态收尾。数据库连接最多等待 10 秒，每条 SQL 执行 15 秒/客户端等待 20 秒；终态通知另有 10 秒限额。没有声称平台硬终止时 finally 必然执行。
