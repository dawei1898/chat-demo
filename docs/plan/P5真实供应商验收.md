# P5 真实供应商验收

## 范围

按用户授权，仅使用合成、不含个人信息的 PNG/TXT/PDF 和公开 example.com 页面进行有限真实 DeepSeek 调用。没有读取旧聊天或上传用户文件，没有调用供应商 DELETE。API Key 仅由探针内部加载，未输出。

本次为**直接上游 API 真实能力验收**，不是浏览器或 Hono/Neon 全链路验收。应用路由和归属/持久化仍以已有隔离集成证据分别说明。

## 结果

| 项目 | 实际结果 |
| --- | --- |
| 合成 64×64 红色 PNG | Files 上传 200，Messages image 引用 200，回答 Red，与样本一致 |
| 合成 UTF-8 TXT | purpose=user_data 上传 200，document 引用 200，正确返回指定测试短语 |
| 合成单页 PDF | purpose=rich_layout_recognition 上传 200，document 引用 200，正确返回同一测试短语 |
| 搜索与读链接 | Messages 返回 200，实际产生 read_link 和 search 调用，包含 1 个带签名结果及 2 个引用 |

上传按服务端契约排列 purpose 在 file 前，图片不传 purpose；使用 Files beta 头。共 3 次文件上传、4 次模型请求，模型输出上限分别 256/256/256/350 tokens。测试进程正常退出。

## 保留和限制

- 供应商上的 3 个合成测试文件未删除。其标识仅记录在 gitignored 本地 manifest，不写入本文或用户消息。
- 未测试跨设备原件下载；供应商不提供该能力，不作此承诺。
- 未测浏览器显示、Hono 实际上传及引用、当前真实账户下的 Neon 持久化，也未测试费用账单准确性。
- 图片/PDF/文本均为极小样本，不代表所有边界格式或供应商配额都已验收。
- 此次没有测试语音；语音验收记录单列，不由上述通过结果推断。
