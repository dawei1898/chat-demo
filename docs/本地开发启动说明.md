## 本机配置
根目录 `.env` 已被 Git 忽略，权限为 600。仅由后端读取。
- `DATABASE_URL`：Neon dev pooled 连接。
- `DATABASE_URL_UNPOOLED`：同一个 dev 的 direct 迁移连接。
- `BETTER_AUTH_SECRET`：本机随机 secret。
- `BETTER_AUTH_URL=http://localhost:8095`。
- `DEEPSEEK_API_KEY`：请在文件内填写新 Key，不在聊天、提交或日志中传递。

始终使用 `http://localhost:8095/`，不要与 `127.0.0.1` 混用。修改 `.env` 后重启后端。

```sh
pnpm install
pnpm db:migrate
pnpm dev:api
# 另一个终端
CHOKIDAR_USEPOLLING=true WATCHPACK_POLLING=true pnpm dev
```

前端 8095，后端仅绑定 127.0.0.1:8096。停服时终端 Ctrl+C。

## P2 认证与注册边界

注册后返回登录页，不自动登录；新注册和重复注册使用通用结果。邮箱仅是登录标识，邮箱验证、密码找回及OAuth已按用户要求取消。

`REGISTRATION_MODE` 默认 `local`，要求配置源和连接来源均为回环地址；`closed` 完全关闭注册。持久限流对本机代理共享来源计数，不适用于未经验证的公网转发链。旧 `local-smoke.mjs` 是会留下dev测试账号/会话的显式烟测脚本，日常优先使用回滚式 `auth-integration.mjs`。

当前已应用到dev的迁移是0000–0003；请使用 `pnpm db:migrate`，不要用 `drizzle-kit push` 替代手写延迟约束。会话失效时前端清空当前内存数据并停止流，不读取或修改旧浏览器历史。
