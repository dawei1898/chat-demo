- 不迁移、不导入、不删除旧 IndexedDB 数据；云端用户从空会话开始。

## 本机配置
根目录 `.env` 已被 Git 忽略，权限为 600。仅由后端读取。
- `DATABASE_URL`：Neon dev pooled 连接。
- `DATABASE_URL_UNPOOLED`：同一个 dev 的 direct 迁移连接。
- `BETTER_AUTH_SECRET`：本机随机 secret。
- `BETTER_AUTH_URL=http://localhost:8095`。
- `DEEPSEEK_API_KEY`：请在文件内填写新 Key，不在聊天、提交或日志中传递。

始终使用 `http://localhost:8095/`，不要与 `127.0.0.1` 混用。修改 `.env` 后重启后端。

```sh
pnpm install
pnpm db:migrate
pnpm dev:api
# 另一个终端
CHOKIDAR_USEPOLLING=true WATCHPACK_POLLING=true pnpm dev
```

前端 8095，后端仅绑定 127.0.0.1:8096。停服时终端 Ctrl+C。
